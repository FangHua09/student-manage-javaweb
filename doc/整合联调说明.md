## 2. 环境准备

1. **JDK 17**（Tomcat 11 最低要求，JDK 21 也可运行，但编译目标为 17）。
   > 本机 PATH 上的 Java 可能是 JDK 21，`pom.xml` 已用 `maven.compiler.release=17` 锁定字节码版本；
   > Tomcat 11 启动时建议设置 `JAVA_HOME=D:\dev\jdk\jdk17`。
2. **Tomcat 11**（Jakarta EE 11 / Servlet 6.1）。不能使用 Tomcat 9 及以下版本。
3. **MySQL 8.0**，确认本机 3306 可用。
4. 项目自带 **Maven Wrapper**，无需单独安装 Maven（Windows 用 `mvnw.cmd`）。
5. 把 `db.properties.template` 复制为 `src/main/resources/db.properties`，填写本机 MySQL 账号密码：

```properties
driver=com.mysql.cj.jdbc.Driver
url=jdbc:mysql://localhost:3306/student_db?useSSL=false&serverTimezone=Asia/Shanghai&characterEncoding=utf8&allowPublicKeyRetrieval=true
username=root
password=你的密码
```

> `db.properties` 已被 `.gitignore` 忽略，**不会**提交到仓库。

## 3. 数据库初始化

```powershell
# PowerShell：不支持 < 输入重定向，用 cmd /c 包一层
cmd /c "mysql -uroot -p --default-character-set=utf8mb4 < sql\student_db.sql"
```

```bat
:: CMD：可直接执行
mysql -uroot -p --default-character-set=utf8mb4 < sql\student_db.sql
```

脚本会创建 `student_db` 库、`t_student` / `t_user` 两张表，并写入 1 个管理员 + 100 名学生。
⚠️ 脚本含 `DROP TABLE`，重复执行会清空已有数据。

## 4. 构建、测试与打包

在项目根目录执行（PowerShell / CMD 均可）：

```powershell
# 1) 运行单元/集成测试（数据库不可用时自动跳过，编译必须通过）
.\mvnw.cmd clean test

# 2) 打包 war
.\mvnw.cmd clean package
```

> CMD 窗口中直接写 `mvnw.cmd ...`；PowerShell 必须写 `.\mvnw.cmd ...`。

产物：`target/student_manage_javaweb.war`（`pom.xml` 已用 `<finalName>` 固定名称）。

测试覆盖：

| 测试类 | 覆盖点 |
| ---- | ---- |
| `DbUtilTest` | 配置加载、真实连接、资源关闭、事务回滚 |
| `UserDaoTest` | 管理员/学生账号查询、修改密码、空密码拒绝（密码用例使用临时测试账号，不改内置账号） |
| `StudentDaoTest` | 主键查询、分页与边界、模糊查询、LIKE 转义、增删改查闭环、班级列表 |

> 集成测试会临时在本机 `student_db` 中创建/删除 `TEST` 前缀的测试数据，测试结束自动清理；
> 测试中断可能残留测试行，重跑测试或重新执行 `sql/student_db.sql` 即可恢复。

## 5. 部署到 Tomcat 11

### 方式一：命令行部署（推荐用于联调自测）

1. 把 `target/student_manage_javaweb.war` 复制到 `%TOMCAT_HOME%\webapps\`。
2. 启动 Tomcat（`%TOMCAT_HOME%\bin\startup.bat`，或 IDEA 中配置）。
3. 浏览器访问：<http://localhost:8080/student_manage_javaweb/login.jsp>
   （上下文路径 = war 文件名 `student_manage_javaweb`）。
4. 账号：管理员 `admin / 123456`；学生任意学号（如 `2024010101 / 123456`）。

### 方式二：IDEA 配置

1. `File → Project Structure → Modules` 确认 Maven 导入正常（JDK 17）。
2. `Run → Edit Configurations → + → Tomcat Server → Local`，选择 Tomcat 11 安装目录。
3. `Deployment` 页签添加 `student_manage_javaweb:war exploded`，Application context 填 `/student_manage_javaweb`。
4. 启动后访问同样的 URL。

### 部署冒烟检查清单

| 检查项 | 预期 |
| ---- | ---- |
| 访问 `/student_manage_javaweb/` | **200**，返回登录页（`welcome-file` 为 `login.jsp`，容器内部转发，不产生 302） |
| 访问 `/student_manage_javaweb/login.jsp` | 200，`Content-Type: text/html;charset=UTF-8` |
| 访问 `/student_manage_javaweb/index.jsp` | 302 跳转到 `login.jsp`（`index.jsp` 是手动访问时的兜底入口） |
| 访问不存在的地址 | 返回定制 404 页面，不是 Tomcat 默认页 |
| 数据库未启动时访问业务页 | 给出错误提示 / 500 错误页，不白屏 |
| 中文姓名、班级显示 | 无乱码 |

## 7. 常见问题（FAQ）

| 现象 | 原因 | 解决 |
| ---- | ---- | ---- |
| `ClassNotFoundException: jakarta.servlet.http.HttpServlet` | 用了 Tomcat 9 及以下 / 混入 `javax.servlet` | 换 Tomcat 11，确认 import 是 `jakarta.servlet.*` |
| `ClassNotFoundException: com.mysql.cj.jdbc.Driver` | 依赖没打进 war / 用了旧 `mysql:mysql-connector-java` 坐标 | 用 `com.mysql:mysql-connector-j`，重新 `mvnw clean package` |
| `classpath 下未找到 db.properties` | 没复制配置文件或放错目录 | 放到 `src/main/resources/db.properties` 并重新构建 |
| 页面 404 | 上下文路径写错 / war 未改名 | 访问 `/student_manage_javaweb/...`，确认 `target` 下 war 名称 |
| 中文乱码 | 页面、请求、数据库连接串编码不一致 | `web.xml` 已统一 UTF-8；数据库连接串保留 `characterEncoding=utf8`；库表 utf8mb4 |
| JSP 报 `Unable to find taglib [http://java.sun.com/jsp/jstl/core]` | JSTL 3.0 改了 URI | 用 `<%@ taglib prefix="c" uri="jakarta.tags.core" %>` |
| 数据库连接失败 | MySQL 未启动 / 密码错 / 时区报错 | 检查 `db.properties`，连接串保留 `serverTimezone=Asia/Shanghai` |
| `mvnw.cmd clean` 失败，提示无法删除 target | 有进程占用 target（如 Tomcat 部署 exploded、日志文件） | 停止 Tomcat / 关闭占用程序后重试 |
| 修改密码后无法登录 | 密码修改没校验旧密码或写错用户主键 | 修改密码必须校验 `oldPassword`，按 `loginUser.getUserId()` 更新 |
| 列表中看到其他学生数据 | 服务端未按角色/学号过滤 | 学生角色只能查 `loginUser.getStuNo()`，不要信任 URL 参数 |
